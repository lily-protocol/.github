##  What is LILY?

**LILY Protocol** is an autonomous finance infrastructure built on the Stellar network that enables AI agents to own wallets, hold assets, execute payments, and transact autonomously on-chain.

Our vision is to power the next generation of AI-native applications with programmable financial infrastructure.

Today, AI systems can automate workflows and generate content, but they cannot independently participate in economic activity. LILY solves this by providing:

- Agent wallet infrastructure
- Autonomous payment execution
- USDC settlement rails
- Agent identity systems
- Developer SDKs
- Runtime infrastructure for AI agents

Built on Stellar, LILY combines fast settlement, low transaction costs, and scalable infrastructure to enable real-world autonomous finance for AI systems.

---

##  Our Mission

LILY’s mission is to build the financial infrastructure layer that allows autonomous AI agents to securely own assets, transact globally, and participate in programmable digital economies.
